# nobu cafe — デモサイト

広島・北広島町の山あいにある抹茶専門の古民家カフェ「nobu cafe」（架空の店舗）のWebサイトです。
WordPressのオリジナルテーマとして制作し、このリポジトリではその表示を静的HTMLとして公開しています。

- 公開URL：https://mmmfumi-code.github.io/NOBU/
- 制作：Fumiya.M

## 主な演出
- 円相が描かれるオープニングと、キャンバスで描く流れる霧
- スクロールに合わせて霧の里山から抹茶の碗の中へ入っていく「一碗へ」
- 摘む・挽く・点てるを横スクロールでたどる「一服ができるまで」
- 見出しの文字送り、画像のクリップ表示、パララックス

使用：WordPress（オリジナルテーマ）、GSAP 3 + ScrollTrigger、Shippori Mincho／Zen Kaku Gothic New

※ 店舗・住所・電話番号・価格・人物はすべて架空です。写真は画像生成AIで作成しています。
